Transparent Proxy

Fetch any http(s) URL through this server.

Request:

How it works

Pass the target as the url query parameter. The server fetches it and streams the response back, CORS-enabled, so browser code can read it.

Examples

curl '/?url=https://example.com'
curl -I '/?url=https://httpbin.org/get'
curl '/?url=https://api.github.com'

Notes

  • Methods: GET and HEAD only; OPTIONS answers preflight.
  • Redirects are followed and the final response is returned.
  • Remote identity headers are stripped before the request reaches the upstream.
  • Response bodies are streamed, so large files work.
  • Configuration is via environment variables: PROXY_ADDR, PROXY_TIMEOUT, PROXY_INSECURE_TLS, PROXY_CORS.
